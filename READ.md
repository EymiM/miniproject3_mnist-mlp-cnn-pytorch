## MNIST Handwritten Digit Classification (MLP vs. CNN)

Handwritten digit classification on the MNIST dataset comparing **Multi-Layer Perceptron (MLP)** and **Convolutional Neural Network (CNN)** architectures implemented in PyTorch.

# How to Run

1. Install the required dependencies:
   ```bash
   pip install -r requirements.txt

2. Run mlp_code or cnn_code to train the respective models and generate the resulting figures (loss curves and confusion matrices). The MNIST dataset is downloaded automatically on the first run.
